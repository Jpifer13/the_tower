# Source Assets

Original downloads in their delivered format (FBX, OBJ, .blend, zips) — kept untouched.

Conversion pipeline: Blender → File → Export → USDZ → output goes to `assets/models/<category>/`. Log any conversion gotchas (scale factors, flipped normals, missing textures) in `docs/learning-notes/usdz-pipeline.md`.

Never edit files here; if a model needs fixing, copy it out, fix, and export.
