# License Archive

One folder per asset, named by manifest ID (`M-001/`, `A-003/`, `H-002/`). Each folder contains:

1. **Receipt** — purchase/download confirmation (PDF or screenshot)
2. **License terms** — PDF or full-page screenshot of the license page **as of the purchase date** (license pages change; the snapshot is your proof)
3. **`notes.md`** — where it came from (URL), date acquired, and anything unusual about the terms

This archive is what you show Apple, a lawyer, or an asset creator if a question ever comes up. Filing it at purchase time takes 2 minutes; reconstructing it a year later is impossible.
